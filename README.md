# PUFF DIVE

LibGDX로 만든 2D 플랫포머 (게임및혼합현실 중간 프로젝트). 분홍 공 캐릭터가 위에서 아래로 미로를 파고 내려가며 적을 빨아들이고 능력을 복사한다.

## 실행

```bash
./gradlew lwjgl3:run
```

창 없이 게임 로직만 자동 점검하려면 `./gradlew lwjgl3:headlessCheck`를 실행한다.

## 조작

| 키 | 동작 |
|---|---|
| ← → | 이동 |
| Z / Space | 점프, 공중에서 다시 누르면 퍼프(최대 3번) |
| X | 흡입. 입에 물면 X로 별 뱉기, ↓로 삼켜서 능력 복사. 능력이 있으면 능력 사용 |
| C | 능력 버리기 |
| ↓ + Z | 얇은 발판 아래로 내려가기 |
| P / ESC | 일시정지·재개 (R 스테이지 재시작, Q 타이틀) |

## 요구사항 대응

| 요구사항 | 구현 |
|---|---|
| 레벨 3개 이상, 2가지 이상 차이 (15%) | Cloud Garden / Crystal Cave / Magma Core. 맵 구조, 등장 적, 배경·타일 테마, 고유 규칙(금 간 블록, 숨은 월드, 용암, 추격 천장)이 모두 다름. 마지막 스테이지를 클리어하면 기록 화면이 나오고 ENTER로 1스테이지부터 다시 시작 |
| 카메라 (10%) | `CameraRig`: 지수 감쇠로 부드럽게 따라가기, 낙하 방향 미리 보기(look-ahead), trauma² 기반 화면 흔들림, 레벨 경계 clamp. 1:1로 붙어 다니지 않음 |
| 독창 요소 3개 이상 (40%) | ① 흡입 → 뱉기/삼키기 → 능력 복사(FIRE, STONE) ② 퍼프 비행(공중 3회, 감속 낙하) ③ STONE 낙하로 금 간 블록 파괴 ④ 맵 밖으로 나가면 중력이 뒤집힌 숨은 글리치 월드 ⑤ 3스테이지 추격 가시 천장 (고무줄 방식) |
| 일시정지 (5%) | P/ESC 언제든 토글, 창 포커스를 잃으면 자동 일시정지 |

## 설계 (수업 예제와 다른 점)

- `Game` + `Screen` 구조: Title → Game → Clear
- 텍스트 파일 기반 레벨(`assets/levels/*.txt`): 타일과 엔티티를 ASCII로 정의하고 힌트 문구도 파일에 넣음
- 타일 그리드 충돌(`Physics`): 걸치는 타일만 검사
- 행동 매핑 입력 계층(`Controls`): 키 여러 개 묶기, 스크립트 자동 입력
- 모든 스프라이트를 `Pixmap`으로 코드에서 생성(`Assets`), 테마 색은 tint로 처리
- GC 없는 배열 풀 파티클(`Particles`), squash & stretch 애니메이션
- 헤드리스 자동 점검(`HeadlessCheck`): 레벨 로드, 흡입, 퍼프, 블록 파괴, 글리치 월드, 천장, 골 판정 시나리오
